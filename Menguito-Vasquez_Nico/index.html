🦆 WHAT IS DUCK TYPING?
A LANGUAGE FEATURE where objects are evaluated based on their METHODS, not their class or type.

🎯 Python checks: "Can this object .quack()?"
🎯 NOT: "Is this a Duck object?"

💡 Key Insight: Duck typing enables FLEXIBLE, REUSABLE code without inheritance hierarchies. Any object with the right method works!
